A collection of **50 classic offline games** written in Python. Play without an internet connection! Cross-platform: works on Windows and Linux (Alt Linux, Ubuntu). Includes both GUI (Pygame/Tkinter) and Terminal versions.

Коллекция из **50 классических оффлайн игр** на Python. Играйте без подключения к интернету! Кроссплатформенность: работает на Windows и Linux (Альт, Ubuntu). Включает версии с графическим интерфейсом (Pygame/Tkinter) и для терминала.

---

## 🖥️ Supported Platforms / Поддерживаемые платформы

- ✅ Windows 10/11
- ✅ Linux: Alt Linux, Ubuntu (и другие дистрибутивы)
- 🐍 Python 3.8+
